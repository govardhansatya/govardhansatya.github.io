# govardhansatya.github.io

## Project Overview

This repository hosts my personal portfolio website using GitHub Pages. It showcases my projects, professional experience, and technical skills. The site serves as an online presence and a way for others to view my work, contact me, or learn more about my background.

## Setup Instructions

1. **Clone the Repository**
   ```bash
   git clone https://github.com/govardhansatya/govardhansatya.github.io.git
   cd govardhansatya.github.io
   ```
## How to Run the Project

### Locally

- **For Static HTML Sites:**
  Open `index.html` in your browser, or use a local server like:
  ```bash
  npx serve .
  # or
  python3 -m http.server
  ```

- **For Jekyll:**
  ```bash
  bundle exec jekyll serve
  ```
  Open your browser at `http://localhost:4000`.

### On GitHub Pages

- Commit and push your changes to the `main` branch.
- GitHub automatically builds and deploys the site at:
  ```
  https://govardhansatya.github.io/
  ```
